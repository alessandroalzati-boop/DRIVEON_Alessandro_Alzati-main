# DriveON

App mobile per il noleggio di auto, sviluppata con Flutter.

## Funzionalità

- Registrazione e accesso utente
- Catalogo delle auto con i dettagli di ogni veicolo
- Preferiti
- Gestione dei noleggi
- Tema scuro

## Tecnologie

- Flutter
- Firebase
